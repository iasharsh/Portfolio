# Harsh Pandey — Portfolio 🌐

A modern, responsive personal portfolio website built with **React, Vite, JavaScript, and Tailwind CSS** to showcase my projects, technical skills, achievements, and resume.

🔗 **Live Demo:** https://portfolio-zeta-eight-tvv9yo50on.vercel.app/

---

## ✨ Features

- 🎬 **Animated Hero Section**
  - Dynamic role titles using `react-simple-typewriter`

- 💼 **Projects Showcase**
  - Dedicated projects page
  - Project cards with descriptions, technologies, and live links
  - Easy-to-maintain project data structure

- 🧠 **Skills Section**
  - Dedicated page showcasing technical skills

- 📄 **Resume Download**
  - Downloadable PDF resume directly from the portfolio

- 🔔 **Toast Notifications**
  - Interactive feedback using `react-toastify`

- 🎨 **Interactive UI**
  - Smooth animations and transitions using Framer Motion

- 📱 **Responsive Design**
  - Optimized for desktop, tablet, and mobile devices

- 🧩 **Reusable Components**
  - Modular React components for maintainable and scalable code

---

## 🛠️ Tech Stack

### Frontend

- React 19
- Vite
- JavaScript
- Tailwind CSS
- Framer Motion
- React Simple Typewriter
- React Toastify
